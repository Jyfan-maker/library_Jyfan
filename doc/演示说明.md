# 图书管理系统 · 演示说明（一页纸）

**作者：** 范记永　**学号：** 2024003296　**题目：** 图书管理系统

## 一、环境要求
- MySQL（本演示机为 26.7.0，utf8mb4）
- JDK 8 及以上（本演示机为 21.0.11）
- Maven 3.9+（仅源码构建时需要；已提供打包好的 jar）

## 二、从零启动步骤

1. **启动 MySQL**（管理员 PowerShell）：
   ```powershell
   Start-Service MySQL267
   ```
2. **导入数据库**（按本机密码调整 -p 后的值）：
   ```powershell
   mysql --default-character-set=utf8mb4 -u root -p123456 < db/library_Jyfan.sql
   ```
   成功会提示：`library_Jyfan 初始化完成：图书 124 本，分类 12 个，SQL 模板 25 条`
3. **修改数据库配置**：编辑 `server/src/main/resources/dbconfig.json`，把 user/password 改成本机 MySQL 账号密码（当前为 root/123456）。若用 jar 运行，需改 jar 内同名文件后重新打包。
4. **启动服务**（二选一）：
   ```powershell
   cd server
   mvn spring-boot:run
   # 或
   java -jar target/library.jar
   ```
5. **打开浏览器**：`http://localhost:8080/login.html`

## 四、演示流程建议（答辩现场随机操作都能应对）
1. 登录 → 图书管理：列表显示 124 本书；搜索框输入"数据库"验证模糊查询。
2. 新增一本图书（选分类、填单价库存）→ 修改它 → 删除它，观察 SQL 与提示。
3. 借书：选一本库存>0 的书借出，观察库存减一；再借同一本应被拦截。
4. 归还：在借阅管理点"归还"，观察库存加一、状态变"已还"。
5. 删除一本有借阅记录的图书：应被外键约束拦截并给出可读提示。
6. 统计报表：总数/库存/总价值，以及按分类的册数与借阅次数条形图。
7. 退出登录后直接访问业务接口：返回 code=401，前端自动跳登录页。

## 五、注意事项
- 修改 sqls 表里的 SQL 后必须**重启服务**才生效（启动时一次性加载进内存）。
- 所有密码在库中均为 MD5 密文，示例明文仅 123456。
- 本项目为新独立库 library_Jyfan，不依赖任何已有数据库。
